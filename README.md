# LearnPlaywright

This repository contains Playwright learning examples and setup verification scripts.

## Structure

- `chapter_01_Basics/` — Introduction to Playwright basics
  - `01_basics.js` — basic Playwright code examples
  - `02_js.js` — JavaScript-specific Playwright examples
  - `03_js_verifySetup.js` — Playwright setup verification script
  - `HotCode.js` — hot code examples

- `chapter_02_Javascript_Concepts/` — Core JavaScript concepts
  - `Comments.js` — JavaScript comments
  - `Identifer_Rules.js` — JavaScript identifier naming rules
  - `JS_Basics.js` — JavaScript basic concepts

- `chapter_03_Identifer_Literals/` — Identifiers and literals
  - `literal_all.js` — All literal types examples
  - `literals.js` — JavaScript literals examples
  - `null_undefined.js` — null and undefined concepts
  - `Single_Literal.js` — Single literal examples
  - `Templete_Literal.js` — Template literal examples

- `chapter_04_Variables/` — JavaScript variables and scoping
  - `const_explained.js` — const keyword explanation
  - `functions.js` — JavaScript functions
  - `Hoisting_withFunctions.js` — Function hoisting examples
  - `let_&_const_hoisting_block.js` — let and const block hoisting
  - `let_&_const_Hoisting_with_TDZ.js` — let and const hoisting with TDZ (Temporal Dead Zone)
  - `let_explained.js` — let keyword explanation
  - `let_functionScoped.js` — let function scoping
  - `realtime_TDZ_jrQA.js` — Real-time TDZ demonstration
  - `var_explained.js` — var keyword explanation
  - `var_functionScoped.js` — var function scoping
  - `var_Hoisting.js` — var hoisting examples
  - `var_let_const.js` — Comparison of var, let, and const

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run a script using Node:
   ```bash
   node chapter_01_Basics/03_js_verifySetup.js
   ```
