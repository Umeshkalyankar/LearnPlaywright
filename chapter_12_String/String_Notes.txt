===============================================
JAVASCRIPT STRING NOTES - Chapter 12
===============================================

1. WHAT IS A STRING?
   - A string is a sequence of characters
   - Immutable - cannot be changed after creation
   - Can be created with single quotes, double quotes, or backticks
   
   Examples:
   let str1 = 'Hello';
   let str2 = "World";
   let str3 = `Template Literal`;

2. STRING CREATION METHODS
   
   a) String Literal:
      let str = 'Hello World';
   
   b) String Constructor:
      let str = new String('Hello World');
   
   c) Template Literal (Backticks):
      let name = 'John';
      let str = `Hello ${name}`;

3. ACCESSING STRING CHARACTERS
   
   - Using Index (0-based):
     let str = 'Hello';
     str[0]      // 'H'
     str[4]      // 'o'
   
   - Using charAt() method:
     str.charAt(0)   // 'H'
   
   - Using charCodeAt() method:
     str.charCodeAt(0)   // ASCII code of 'H' (72)

4. STRING PROPERTIES
   
   a) length:
      let str = 'Hello';
      str.length   // 5
   
   b) index (using bracket notation):
      str[0]   // 'H'

5. STRING METHODS - MODIFICATION
   
   a) toUpperCase():
      'hello'.toUpperCase()   // 'HELLO'
   
   b) toLowerCase():
      'HELLO'.toLowerCase()   // 'hello'
   
   c) trim():
      '  hello  '.trim()   // 'hello' (removes leading/trailing spaces)
   
   d) trimStart() / trimEnd():
      '  hello  '.trimStart()   // 'hello  '
      '  hello  '.trimEnd()     // '  hello'
   
   e) repeat():
      'ab'.repeat(3)   // 'ababab'
   
   f) padStart() / padEnd():
      '5'.padStart(3, '0')   // '005'
      '5'.padEnd(3, '0')     // '500'

6. STRING METHODS - SEARCHING
   
   a) indexOf():
      'hello world'.indexOf('o')   // 4
      'hello world'.indexOf('x')   // -1 (not found)
   
   b) lastIndexOf():
      'hello world'.lastIndexOf('o')   // 7
   
   c) includes():
      'hello world'.includes('world')   // true
      'hello world'.includes('xyz')     // false
   
   d) startsWith():
      'hello world'.startsWith('hello')   // true
      'hello world'.startsWith('world')   // false
   
   e) endsWith():
      'hello world'.endsWith('world')   // true
      'hello world'.endsWith('hello')   // false

7. STRING METHODS - EXTRACTION
   
   a) charAt():
      'hello'.charAt(1)   // 'e'
   
   b) slice():
      'hello'.slice(1, 4)   // 'ell' (index 1 to 3)
      'hello'.slice(-3)     // 'llo' (last 3 characters)
   
   c) substring():
      'hello'.substring(1, 4)   // 'ell'
      Note: Cannot use negative indices
   
   d) substr():
      'hello'.substr(1, 3)   // 'ell' (start at 1, length 3)

8. STRING METHODS - REPLACEMENT
   
   a) replace():
      'hello world'.replace('world', 'JS')   // 'hello JS' (first occurrence)
   
   b) replaceAll():
      'hello hello'.replaceAll('hello', 'hi')   // 'hi hi'

9. STRING METHODS - SPLITTING & COMBINING
   
   a) split():
      'a,b,c'.split(',')   // ['a', 'b', 'c']
      'hello'.split('')     // ['h', 'e', 'l', 'l', 'o']
   
   b) concat():
      'hello'.concat(' ', 'world')   // 'hello world'

10. STRING METHODS - ARRAY-LIKE OPERATIONS
    
    a) match():
       'hello123world'.match(/\d+/)   // ['123']
    
    b) search():
       'hello'.search('l')   // 2

11. TEMPLATE LITERALS (Backticks)
    
    a) Basic Syntax:
       let name = 'John';
       let age = 30;
       let str = `Name: ${name}, Age: ${age}`;
    
    b) Multi-line Strings:
       let str = `Line 1
                 Line 2
                 Line 3`;
    
    c) Expression in Template:
       `Sum: ${2 + 3}`   // 'Sum: 5'

12. STRING IMMUTABILITY
    
    - Strings cannot be modified once created
    - Operations on strings return NEW strings
    
    Example:
    let str = 'hello';
    str[0] = 'H';   // This does NOT change the string
    str              // Still 'hello'
    
    str = str.replace('h', 'H');   // This creates a new string
    str              // Now 'Hello'

13. STRING COMPARISON
    
    a) Equality:
       'abc' === 'abc'   // true
       'abc' == 'abc'    // true
    
    b) Comparison (lexicographic):
       'a' < 'b'         // true
       'abc' < 'abd'     // true (c < d)

14. TYPE CONVERSION TO STRING
    
    a) Using String() constructor:
       String(123)   // '123'
       String(true)  // 'true'
    
    b) Using toString():
       (123).toString()   // '123'
    
    c) Using Template Literal:
       `${123}`   // '123'

15. COMMON STRING PATTERNS
    
    a) Email validation:
       Contains '@' and '.' ? (Basic check)
    
    b) Password strength:
       Check length, uppercase, lowercase, numbers, special chars
    
    c) URL validation:
       Use regex or check for 'http://' or 'https://'
    
    d) Phone number:
       Check length and numeric format

16. KEY DIFFERENCES: SIMILAR METHODS
    
    slice() vs substring():
    - slice() accepts negative indices, substring() doesn't
    - slice(-3) gets last 3 chars; substring(-3) treats as 0
    
    indexOf() vs search():
    - indexOf() searches for string value
    - search() can accept regex pattern
    
    replace() vs replaceAll():
    - replace() replaces only first occurrence
    - replaceAll() replaces all occurrences

17. PERFORMANCE TIPS
    
    - Use concatenation (+) or template literals for combining strings
    - For heavy string operations, consider arrays and join()
    - Avoid creating unnecessary string objects with new String()
    - Use const for string variables that won't be reassigned

18. COMMON ERRORS
    
    a) Treating strings as mutable:
       str[0] = 'x';   // Doesn't work
    
    b) Forgetting return value:
       str.toUpperCase();   // If not assigned, original str unchanged
    
    c) Index out of bounds:
       'hello'[10]   // undefined (no error, just returns undefined)

===============================================
QUICK REFERENCE - STRING METHODS BY CATEGORY
===============================================

📌 CASE CONVERSION:
   toUpperCase()       → Convert to uppercase
   toLowerCase()       → Convert to lowercase

📌 TRIMMING:
   trim()              → Remove spaces from both ends
   trimStart()         → Remove spaces from start
   trimEnd()           → Remove spaces from end

📌 SEARCHING:
   indexOf(str)        → First index of substring (-1 if not found)
   lastIndexOf(str)    → Last index of substring
   includes(str)       → Check if contains substring (boolean)
   startsWith(str)     → Check if starts with substring
   endsWith(str)       → Check if ends with substring

📌 EXTRACTION:
   charAt(index)       → Get character at index
   slice(start, end)   → Extract part (supports negative index)
   substring(start, end) → Extract part (no negative index)
   substr(start, len)  → Extract part (deprecated - use slice)

📌 REPLACEMENT:
   replace(old, new)   → Replace first occurrence
   replaceAll(old, new) → Replace all occurrences

📌 SPLITTING & JOINING:
   split(separator)    → Convert string to array
   concat(str1, str2)  → Join strings together

📌 REPETITION & PADDING:
   repeat(count)       → Repeat string n times
   padStart(len, char) → Pad string from left
   padEnd(len, char)   → Pad string from right

TEMPLATE LITERALS CHEAT CODE
===============================================

Syntax: `string with ${expression}`

Examples:
┌──────────────────────────────────────┬────────────────────────────────────┐
│ CODE                                 │ OUTPUT                             │
├──────────────────────────────────────┼────────────────────────────────────┤
│ `Hello World`                        │ Hello World                        │
│ `Hello ${name}`                      │ Hello John (if name = 'John')      │
│ `${2 + 3}`                           │ 5                                  │
│ `${true ? 'Yes' : 'No'}`             │ Yes                                │
│ `Cost: $${100 * 2}`                  │ Cost: $200                         │
│ `${str.toUpperCase()}`               │ HELLO (if str = 'hello')           │
└──────────────────────────────────────┴────────────────────────────────────┘
